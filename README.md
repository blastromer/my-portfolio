# Romer Necesario Portfolio

Simple static portfolio site ready for GitHub + Vercel deployment.

## Run locally

Open `index.html` directly in your browser, or use any local static server.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, click **Add New Project**.
3. Import the GitHub repo.
4. Framework preset: **Other**.
5. Build command: leave empty.
6. Output directory: leave empty (root).
7. Deploy.

Any new push to `main` will auto-deploy.

## Enable contact form

1. Create a free form in Formspree.
2. Copy your endpoint (example: `https://formspree.io/f/abcxyzpq`).
3. Update the form `action` in `index.html`.
4. Deploy again to Vercel.
